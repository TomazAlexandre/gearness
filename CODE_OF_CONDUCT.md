# Code of conduct

This project is a friendly place to build tools for working with AI agents. Contributors and maintainers commit to:

- be respectful and assume good intent, especially with newcomers;
- critique ideas and code, never people;
- keep discussions on topic and constructive;
- not tolerate harassment, discrimination or personal attacks in any form.

Maintainers may edit or remove comments, issues and contributions that break these rules, and may block repeat
offenders. Report problems privately to the maintainer through GitHub (https://github.com/TomazAlexandre).
